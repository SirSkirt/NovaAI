# Teaching Nova V7 — Alpha 9.3

Native teaching remains a Rust-owned brain operation.

```text
raw teaching
  -> Basic English structural substrate
  -> Rust source/semantic interpretation
  -> Rust semantic memory
  -> Rust cognitive translation
  -> Rust synthesis / Stored Only decision
```

## School-entry English boundary

The built-in Basic English bootstrap exists only so Nova can understand simple Year 1 teaching language. It is not an English course embedded in code.

Allowed substrate behavior includes preserving words, sentence/quotation boundaries, phrase groupings, simple relations, basic negation/coordination, simple question/request cues, deictic/reference mechanics and a very small amount of English glue.

Do not put Year 1 knowledge into the bootstrap. Concepts such as names, pronouns as a taught category, people/things/actions as concepts, questions/answers as learned concepts, context, reasons, possibilities, knowing/not knowing, reflection, school, lesson, teacher, student, tests, grammar terminology and reasoning remain learnable.

Rule of thumb:

> **Enough English to attend school, not enough English to skip school.**

If a simple lesson cannot be structurally represented, improve the generic Rust substrate. If Nova can represent it but lacks the concept, teach the concept. Do not hardcode the lesson answer.

## Teacher/test feedback

Rust preserves together:

- lesson/source context and test/case identity;
- immutable original question;
- immutable Nova answer;
- attempt number;
- automatic grading context;
- expected answer/behavior used by the evaluator;
- points, optional percent and optional grade;
- Teacher Notes;
- exact strike/highlight/underline spans and optional note per span;
- authoritative Rust Thinking trace;
- compact cognitive and Brain Inspector context;
- date/timestamps and Teacher provenance.

Teacher feedback is **non-executable Knowledge**. It may later be retrieved as evidence for reflection, but it is never compiled directly into a behavior rule.

During an active multi-question test, answer-key/grading evidence remains unreleased until Rust finalizes the full run. This prevents question-to-question leakage.

## Reflection

Start Reflection is only a Teacher action that sends a normal Teacher utterance through Nova's ordinary input path. Teacher follow-up questions are external Teacher prompts, not Nova-generated thoughts.

Nova's own conclusions/questions/patterns must arise from the current Rust cognition and learned abilities. If Nova does not yet know how to reflect, the correct behavior is to need scaffolding or remain blocked—not to invoke a scripted reflection tree.
