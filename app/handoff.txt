====================
Updated for: Nova V7.0.0-alpha.9.3.1 — Alpha 9.3 Compile Fix

PURPOSE OF THIS FILE
--------------------
This is the permanent project handoff. Read it before changing Nova. The Issues ledger is permanent: do not delete resolved issues. Update their status/version if they regress or are superseded.

PROJECT OVERVIEW
----------------
Nova is a developmental local AI/cognitive architecture built in Tauri. Nova is intended to learn semantic knowledge, reusable cognitive structures, relationships, categories, experience routes, abstractions and internal goals through teaching and experience. Generic substrate machinery belongs in code; curriculum answers and phrase-specific behavior do not.

V7 completed the authoritative brain migration from JavaScript to Rust in Pass 9. Native Tauri JavaScript is now UI/presentation + thin IPC only. Historical JavaScript cognition code may remain for browser-only development/regression, but it is not loaded as native authority, does not hydrate the native mind, and is never a Rust fallback.

CRITICAL ARCHITECTURAL RULES
----------------------------
1. ONE CURRENT MIND. Rust `NovaMind` is native Nova.
2. Improve/replace current architecture in place. Never old system -> wrapper -> new wrapper.
3. No Rust-fails -> JS-Nova fallback. A Rust failure is an error/blocked current mind.
4. Do not hardcode answers, question-word mappings, phrase-specific behavior, or curriculum facts into the substrate.
5. Built-in primitives/categories are generic bootstrap machinery, not a closed ontology.
   - Alpha9.3 Basic English is structural school-entry substrate only: enough English to attend school, not enough English to skip school. Do not preteach classroom grammar/semantic concepts through it.
6. Stored Only is legitimate developmental state and can awaken after later capability learning.
7. Experience routes are Nova-built from successful cognition. They guide attention but never forbid broadening.
8. Free thought/internal goals use the same Rust executive as user goals. No autonomous second brain.
9. Response meaning and terminal state are Rust-owned. JS renders the returned realization.
10. Rust conversation history/discourse chooses cognitive context. JS does not select prior chat context for Nova.
11. Rust owns the complete durable mind payload, hydration, migration, serialization, recovery and reset.
12. JS may provide opaque UI state (chat display/Thinking/technical telemetry history) to a checkpoint; it may not provide or replace `NovaMind`.
13. Keep Rust modular. `NovaMind` coordinates focused subsystems rather than becoming a monolith.
14. Stable persistence location remains Tauri `app_data_dir()` for `com.qtech.nova`; never create per-version minds.
15. External app/tool authorization remains separate from cognition.

ISSUE-048 — Pre-hydration/frontend saves could outrank the real durable mind; completed actions could also return before disk commit
Status: FIXED IN V7 ALPHA6.1 — LIVE UPDATE VALIDATION REQUIRED
Problem: `memory.js` loads before the native persistence bridge and async bootstrap.
