# Nova V7 Pass 4 — Controlled App Access

External control remains a trusted-host capability, not learned cognition.

1. Access starts disabled.
2. The user selects and approves one visible target window/application.
3. Rust owns and revalidates the runtime grant.
4. Nova's mind may propose an action but cannot grant itself authority.
5. Restarting/revoking access ends the grant; learned memory cannot restore permission.

Pass 4's learned cognitive-module migration does **not** grant cognitive modules shell/filesystem/process/window authority. The trusted external capability boundary remains separate from the learned brain runtime.
