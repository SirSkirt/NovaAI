# Nova v0.13.1 — Diagnosing two-pathway usefulness without changing learning

This update alters *only diagnostic reporting*, not optimizer mathematics, learned weights, neural architecture, inference defaults, existing SVG brain visualizer, checkpoint structure or Android signing identity.

## Gradient clipping
Both Dense and Transformer use a preclip global gradient-norm threshold of exactly 1.0. In v0.13.0 the epoch screen showed raw mean norms and the fraction of supervised batches above threshold. It now also shows the actual scaling factors, min(1, 1/norm), averaged across observed supervised batches. Targeted optimizer masks correctly report only active Transformer parameter gradients, while frozen weights do not falsely count as clipped. No clipping threshold or learning rate is changed. Adam can be substantially insensitive to globally scaling a gradient; a mean clipping scale is not the same as an effective learning-rate multiplier.

## Held-out integrity
The training observer used to show the first held-out example per category, often a conversation greeting that appeared in training under a different session. This update indexes canonical prompt starts from all training categories, chooses a prompt absent from training where possible, and prioritizes meaningful conversation follow-up questions that use memory. All held-out prompts (not just displayed ones) are audited for exact overlap with training. An unavoidably repeated prompt is displayed with an explicit warning instead of claimed independent. Existing train/validation assignments are not changed in this diagnostic-only phase, so historical matched comparisons remain comparable. Exact prompt novelty does not rule out paraphrase/topic contamination.

## Three-way response comparison
For each selected held-out category and the same immutable checkpoint, prompt and prior turns, record independent greedy generated answers for: Full brain, no dense pathway, and no reciprocal exchange. Each is capped at 12 generated characters. Separately record the teacher-forced mean NLL of the expected answer for each pathway condition. The teacher reference answer is used *only for scoring*, never in Nova's autoregressive generation or gradient updates. The recorded benefit fields equal NLL(ablated) minus NLL(full): positive favors cooperative full brain, negative favors the ablated version. Such changes diagnose help or interference on that probe, not proof of generalized reasoning. These measurements require CPU time on mobile hardware.
